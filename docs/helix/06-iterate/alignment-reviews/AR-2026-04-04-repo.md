## Implementation Map

- **Topology**: Single Go module (`github.com/easel/dun`) with `cmd/dun/` (CLI entry), `internal/dun/` (core engine, 90.8% coverage), `internal/plugins/builtin/` (embedded plugins), `internal/update/` (self-update), `internal/version/` (version info)

- **Public Interfaces**: CLI flags and subcommands; YAML plugin manifests; JSON/LLM output formats; `dun` frontmatter schema
- **Tests**: 5 packages pass (`cmd/dun` 8.9s, `internal/dun` 90.8% coverage, `internal/plugins/builtin`, `internal/update`, `internal/version`). All tests green.
